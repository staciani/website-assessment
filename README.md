# Giorno e Notte

**A menu for every moment.** Giorno e Notte is a restaurant website with fresh, nourishing lunches by day, comforting dinners by night, and a warm atmosphere in between.

## Explore

- **Home** — the restaurant story, team, and a day-to-night New York slideshow.
- **Lunch** — light, fresh dishes for daytime.
- **Dinner** — comforting dishes for the evening.
- **Contact** — restaurant contact details.

## Publish with GitHub Pages

1. Create a GitHub repository named `giorno-e-notte`.
2. Upload the contents of this folder, keeping `index.html` at the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the website URL in the Pages settings when publishing is ready.

After publishing, you can continue editing the files and upload or push your updates to the same repository. The website keeps the same URL.

## Run locally

Open `index.html` in a browser. The menu, styles, scripts, fonts, and images are included in this repository.
